# GrabMii
## By Null

**GrabMii is a tool to backup and import your Miis to/from a storage device, and convert Wii U and 3DS Miis.**

In more detail, this app allows you to:

  * Backup your Miis to a file directly on your storage device (choose from `.miigx`, `.mae`, or `.rcd`)
  * Import said Mii files from said storage device directly to the Mii Channel
  * Convert Wii U and 3DS format Miis (`.ffsd` and/or `.cfsd`) to a Wii format Mii (`.miigx`, `.mae`, or `.rcd`)
  * Delete Miis directly from the app
  * Backup your Mii Database (`RFL_DB.dat`) to your storage device (as `RFL_DB_0X.bak`)

The app is very straightforward to use, and fairly easy to troubleshoot as well 👍
